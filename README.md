# 📈 주식 투자 매니저 (KOSPI 100)

매 평일 장 마감 후 자동으로 데이터를 수집·채점하고, **다음 날 예약매매(지정가 매수 / 손절·매도)를 결정할 수 있는 대시보드**를 생성하는 개인용 시스템입니다.

- 대시보드: `docs/index.html` (GitHub Pages로 서빙 → 저녁에 휴대폰으로 확인)
- 매매 기록: `docs/trade.html` (매수/매도 입력 → CSV 복사 → `data/my_trades.csv`에 붙여넣기)
- 투자 논리: `docs/journal.html` (진입 논리·반대 논리·무효화 조건 기록 → `data/journal.csv`)

## 🧭 판단에 들어가는 6가지 (종목을 터치하면 순서대로 나옵니다)

| # | 요소 | 어디서 나오나 | 무엇을 답하나 |
|---|---|---|---|
| 1 | **판단 요약** (A~D 등급) | `thesis.verdict` | 지금 이 종목에 대해 뭘 해야 하나, 근거는 얼마나 두꺼운가 |
| 2 | **상승 시나리오** | `thesis.bull_case` | 왜 오를 수 있나 · **그 논리가 성립하려면 무엇이 참이어야 하나** |
| 3 | **하락·반대 논리** | `thesis.bear_case` | 왜 틀릴 수 있나 (13가지 자동 체크) · **무효화 조건** |
| 4 | **확률 계산** | `thesis.probability` | 승률·신뢰구간·기대값·손익비·켈리 비중 |
| 5 | **시장 상황별 시나리오** | `regime.py` + 베타 | 시장이 −20%~+10%일 때 이 종목·내 계좌는 |
| 6 | **최신 뉴스** | `news.py` | 위 논리를 뒤집을 사건이 있나 |

> 등급은 **"오른다"는 예측이 아니라 "같은 잣대로 100종목을 줄 세웠을 때 근거가 어디쯤인가"** 입니다.
> 개별 종목의 30일 승률은 이 데이터로 **통계적으로 입증되지 않으며**, 대시보드가 그 사실을 종목마다 그대로 표시합니다.

## 🗓 하루 사용 흐름

1. **17:00** GitHub Actions(`daily.yml`)가 자동 실행 → 데이터 갱신·채점·리포트 생성·커밋.
2. **저녁** 대시보드(`index.html`)를 열어 확인:
   - 🔴 손절 / 🔵 매도 / 🟢 지금 사기 좋은 순서(BuyFit) / 💼 내 계좌
   - 종목을 터치 → 그래프·점수근거·과거 유사사례 승률·매수밴드·기대손익
3. 결정한 주문을 **증권사 앱에 예약**(지정가 매수, 손절가 매도).
4. 실제 체결되면 `trade.html`로 기록 → CSV를 `data/my_trades.csv`에 반영(커밋).

## 🧮 점수 엔진 (`src/score.py` + `config/weights.yaml`)

매 거래일 종목 간 **횡단면 백분위(0~100)** 로 각 팩터를 표준화한 뒤 가중합.

| 팩터 | 가중치 | 내용 |
|---|---|---|
| 가치(value) | 0.32 | PER·PBR (낮을수록 高) — 종가/EPS, 종가/BPS |
| 수익성(profit) | 0.22 | ROE + 영업이익률 + ROE개선추세 |
| 수급(flow) | 0.20 | 외국인 20일 순매수 / 시가총액 (횡단면 z) |
| 성장(growth) | 0.18 | 매출·영업이익·순이익 전년동기 성장률 |
| 모멘텀(momentum) | 0.08 | 20·60일 + 12-1개월(단기반전 제거) |
| 안정성/거래추세/감성 | 0.00 | 계산은 되나 현재 미사용 |

- **미래참조 차단**: 재무는 `사용가능일` 기준 as-of(backward) join.
- 결측은 중립 50점으로 채움.

## 📊 매매 전략 (`src/signal.py`)

- 종합점수 **상위 20 풀**, **10위 이내** 진입, 보유가 **20위 밖**으로 이탈 + **최소 30거래일** 보유 시 매도.
- **손절 -10%**, **트레일링 스탑 -8%**(진입 후 고점 대비) — 둘 중 먼저 닿는 값이 감시가.
- **외국인 순매도** 종목은 매수 보류(⚪).
- **BuyFit** = z(종합점수) + 0.25 × 타이밍, 타이밍 = 0.6·(-z 60일낙폭) + 0.4·(-z 20일수익) → 단기 평균회귀. "점수는 좋은데 지금 눌린" 종목을 앞으로.

## 🎲 확률 계산 (`src/thesis.py`)

과거 **점수·타이밍이 비슷했던 같은 종목의 실제 사례**들이 30거래일 뒤 어떻게 됐는지를 분포로 제시합니다.
"오른다"고 말하지 않고 분포만 말하는 것이 원칙입니다. 여기서 **정직함을 지키는 장치가 셋** 있습니다.

**1) 표본 겹침 보정 (`independent_n`)**
30일 창을 매일 표집하면 인접 표본은 29/30이 같은 구간이라 사실상 1개입니다.
표본 265개가 그대로 265개의 증거인 척하면 신뢰구간이 실제보다 **5배 이상 좁아져** "확실해 보이는 착시"가 생깁니다.
그래서 정렬 후 30거래일 간격을 두고 고르는 그리디 선택으로 **겹치지 않는 관측치 수**를 실측합니다 (265회 → 독립 20회).
Wilson 신뢰구간은 이 **독립표본 수**로 계산합니다.

**2) 기준선 대비 초과승률 (`base_win`)**
승률 60%는 높아 보이지만, 아무 종목이나 아무 날 사도 30일 뒤 오를 확률이 이 표본에선 **48.4%** 입니다.
따라서 엣지는 승률이 아니라 **승률 − 기준선**입니다. 대시보드는 신뢰구간 띠와 기준선을 겹쳐 그려,
**띠가 기준선을 확실히 넘는 종목이 거의 없다**는 사실을 숨기지 않습니다 (`prob.proven` 필드).

**3) 켈리 비중을 세 겹으로 깎음**
연속수익 근사 `f* ≈ μ/σ²`를 쓰되(2결과 공식은 손절 때문에 수백 %로 튀어 무의미),
① 기대수익에서 **추정오차 1σ** 차감 → ② 동시보유 **10종목**으로 나눔 → ③ 상한 20% + **절반만** 사용.
결과가 0%면 "이 표본으로는 비중을 키울 근거가 없다"는 뜻이고, 실제로 100종목 중 60여 개가 0%로 나옵니다.
**최종 수량은 켈리와 손실예산(원금의 1~2%) 중 작은 쪽**으로 정하세요.

기대값은 실제 전략대로 **-10% 손절을 적용**하고 왕복비용 0.3%를 뺀 값입니다.

## 🌡 시장국면 (`src/regime.py`)

종목 점수는 "같은 시장 안에서 누가 나은가"(횡단면)만 말합니다. 시장이 무너지면 1위 종목도 같이 빠집니다.
그래서 KOSPI100 등가중 지수로 **그날 알 수 있는 정보만** 써서 국면을 나눕니다.

| 국면 | 조건 | 이 전략의 과거 30일 승률 |
|---|---|---|
| 🔥 강세장 | 200일선 위 + 60일선 위 종목 ≥55% | 65.8% (시장대비 +1.0%p) |
| 😐 횡보장 | 200일선 위지만 상승 폭 좁음 | 54.6% (+0.7%p) |
| 🌧 약세장 | 200일선 아래 | 53.9% (+1.7%p) |
| ⛈ 급락장 | 고점대비 −15% 이하 | 65.1% (−0.1%p) |

여기에 **국면 전이확률**(30일 뒤 어떤 국면일지 과거 빈도)과 **종목별 베타/하락베타**를 계산해,
"시장이 −20%면 내 계좌는 얼마가 되고 몇 종목이 손절에 걸리는가"를 계좌 카드에 표로 띄웁니다.
※ 베타는 과거 평균이라 **진짜 급락장에서는 상관이 1로 수렴해 표보다 나빠지는** 경향이 있습니다.

## 📓 투자 논리 기록 (`docs/journal.html`)

사기 **전에** 논리를 적어두지 않으면, 결과가 나온 뒤 기억이 조용히 그 결과에 맞춰 바뀝니다(사후과잉확신).

- 대시보드 종목 화면 → **"✍️ 논리 기록하기"** → 상승·반대 논리·목표가·손절가·무효화 조건이 **자동 초안**으로 채워집니다 (그대로 두지 말고 본인 말로 고쳐 쓰는 것이 핵심).
- 반대 논리를 비운 채 저장하려 하면 한 번 막습니다(확증편향 방어).
- 기록 시점 주가가 함께 저장돼 **"내 판단 이후 실제로 어떻게 됐나"** 를 대조합니다.
- **무효화 점검** 카드가 기록해둔 손절가·순위를 오늘 데이터와 자동 대조해 걸린 항목을 띄웁니다.
- CSV를 `data/journal.csv`에 커밋하면 다음 날부터 종목 화면에 그 기록이 함께 표시됩니다.

## ⚠️ 한계 (반드시 인지)

- **생존편향**: `prices.csv`는 2026년까지 살아남은 현재 KOSPI 100종목을 2018년까지 백필한 것. 실제 상장폐지 종목(약 4,000건)은 데이터에 없어, 백테스트 수익은 **실전보다 높게** 나옵니다.
- `data/universe.csv` 스냅샷이 1개뿐이라 point-in-time 생존편향 보정은 아직 **미작동**(대시보드는 이를 정직하게 "일부만 보정"으로 표시). 장기적으로 월간 스냅샷을 쌓으면 개선됩니다.
- `robust_backtest.py`의 Sharpe/연율은 30일 수익을 **매일 중첩 표집**해 정밀도를 과대평가합니다. 표본은 강세장 비중이 큰 2018~2026 구간 → **실전 기대는 더 보수적으로**.
- `data/shorts.csv`(공매도)는 2026-06-22부터 수집만 되고 아직 점수에 미반영. `verify_factor.py` 검증 후 팩터화 예정.
- **개별 종목의 승률은 통계적으로 입증되지 않습니다.** 겹침 보정을 하면 종목당 독립 관측치가 보통 5~25회뿐이라 95% 신뢰구간이 ±20%p 넘게 벌어집니다. A등급은 "입증됐다"가 아니라 **"같은 잣대에서 상대적으로 근거가 두껍다"** 입니다.
- **뉴스 감성은 제목 키워드 사전으로만 매깁니다.** 반어·맥락·물타기 기사를 구분하지 못하므로 점수에 반영하지 않고 참고 표시만 합니다. 강한 악재 키워드만 반대 논리로 승격됩니다.
- **베타는 최근 250일 평균**이라 국면이 바뀌면 빗나갑니다. 급락장에서는 종목 간 상관이 1에 수렴해 스트레스 테스트 결과보다 실제가 더 나쁩니다.
- 국면별 통계의 **급락장 표본이 가장 얇습니다**(정작 가장 궁금한 칸). 그 줄의 숫자는 특히 믿지 마세요.
